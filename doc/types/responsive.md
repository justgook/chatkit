# Responsive

`Responsive<T>` accepts a scalar `T` or a responsive object with a required `default` value and breakpoint overrides. Breakpoint names: `xs`, `sm`, `md`, `lg`, `xl`, `2xl`.

Breakpoints refer to container width. Exact thresholds, fallback order, invalid-value handling, and numeric coercion remain design decisions. Grid uses this shape for columns, gaps, and item spans.
